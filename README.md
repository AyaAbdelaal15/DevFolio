# DevFolio

A responsive personal portfolio website built with HTML5, CSS3, Bootstrap 5, and JavaScript.

## 🌐 Live Demo

https://dev-folio-theta-two.vercel.app/

## 📌 Features

- Responsive design
- Bootstrap navbar
- Hero section
- About section
- Skills progress bars
- Services section
- Portfolio section
- Testimonials carousel
- Blog section
- Contact section
- Responsive mobile layout
- Font Awesome icons

## 🛠️ Technologies

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Font Awesome
